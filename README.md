# orchestrate-parallel-work

一个独立发布的 Agent Skill，用于判断复杂任务是否值得拆分，并在授权范围内组织隔离工作单元、分波次执行、统一集成和独立终验。

## 文件

- `SKILL.md`：完整的 skill 定义和执行规范。
- `agents/openai.yaml`：Codex/OpenAI 界面元数据。
